## Neo4j Schema Definition

### Node Types

#### Article
```
- uuid (string, primary key)
- fk_id (string)
- headline (string)
- url (string)
- author (string)
- pub_date (string)
- story_type (string)
```

#### Location
```
- uuid (string, primary key)
- name (string)
- original_text (string)
- type (string)
- importance (string)
- description (string)
- latitude (float)
- longitude (float)
```

#### Person
```
- uuid (string, primary key)
- name (string)
- wikidata_id (string)
- wikidata_label (string)
```

### Relationships
```
(l:Location)-[:MENTIONED_IN]->(a:Article)
(p:Person)-[:MENTIONED_IN]->(a:Article)
```

### Database Constraints & Indexes
```cypher
// Unique constraints on primary identifiers
CREATE CONSTRAINT ON (a:Article) ASSERT a.uuid IS UNIQUE;
CREATE CONSTRAINT ON (l:Location) ASSERT l.uuid IS UNIQUE;
CREATE CONSTRAINT ON (p:Person) ASSERT p.uuid IS UNIQUE;

// Indexes for faster lookups
CREATE INDEX ON :Article(url);
CREATE INDEX ON :Location(name);
CREATE INDEX ON :Person(name);
```

### Data Flow Transformation
**Current:** Processing Pipeline → S3 Buckets

### Expected Data Operations

#### 1. Create Article Node
```python
def create_article(session, article_data):
    query = """
    CREATE (a:Article {
        uuid: $uuid,
        fk_id: $fk_id,
        headline: $headline,
        url: $url,
        author: $author,
        pub_date: $pub_date,
        story_type: $story_type
    })
    RETURN a.uuid as uuid
    """
    return session.run(query, article_data)
```

#### 2. Create Location Node
```python
def create_location(session, location_data):
    query = """
    MERGE (l:Location {uuid: $uuid})
    ON CREATE SET 
        l.name = $name,
        l.original_text = $original_text,
        l.type = $type,
        l.importance = $importance,
        l.description = $description,
        l.latitude = $latitude,
        l.longitude = $longitude
    RETURN l.uuid as uuid
    """
    return session.run(query, location_data)
```

#### 3. Create Person Node
```python
def create_person(session, person_data):
    query = """
    MERGE (p:Person {uuid: $uuid})
    ON CREATE SET 
        p.name = $name,
        p.wikidata_id = $wikidata_id,
        p.wikidata_label = $wikidata_label
    RETURN p.uuid as uuid
    """
    return session.run(query, person_data)
```

#### 4. Create Mention Relationships
```python
def create_location_mention(session, location_uuid, article_uuid):
    query = """
    MATCH (l:Location {uuid: $location_uuid})
    MATCH (a:Article {uuid: $article_uuid})
    CREATE (l)-[:MENTIONED_IN]->(a)
    """
    session.run(query, {
        'location_uuid': location_uuid,
        'article_uuid': article_uuid
    })

def create_person_mention(session, person_uuid, article_uuid):
    query = """
    MATCH (p:Person {uuid: $person_uuid})
    MATCH (a:Article {uuid: $article_uuid})
    CREATE (p)-[:MENTIONED_IN]->(a)
    """
    session.run(query, {
        'person_uuid': person_uuid,
        'article_uuid': article_uuid
    })
```

### Transaction Management
```python
def write_article_with_entities(driver, article_data, locations, persons):
    with driver.session() as session:
        with session.begin_transaction() as tx:
            # Create article
            article_result = tx.run(create_article_query, article_data)
            article_uuid = article_result.single()['uuid']
            
            # Create locations and relationships
            for location in locations:
                tx.run(create_location_query, location)
                tx.run(create_location_mention_query, {
                    'location_uuid': location['uuid'],
                    'article_uuid': article_uuid
                })
            
            # Create persons and relationships
            for person in persons:
                tx.run(create_person_query, person)
                tx.run(create_person_mention_query, {
                    'person_uuid': person['uuid'],
                    'article_uuid': article_uuid
                })
```

## Implementation Notes

### Key Considerations
1. **UUID Generation:** Ensure consistent UUID generation for entities
2. **MERGE vs CREATE:** Use MERGE for entities that might already exist (Location, Person), CREATE for unique articles
3. **Transaction Management:** Wrap related operations in transactions for data consistency
4. **Error Handling:** Implement proper error handling for database operations
5. **Connection Management:** Properly manage Neo4j driver connections and sessions

### Performance Recommendations
1. **Batch Operations:** Consider batching multiple article creations for better performance
2. **Index Usage:** Leverage indexes on uuid fields for fast lookups
3. **Connection Pooling:** Use Neo4j driver's built-in connection pooling

### Data Integrity
1. **Unique Constraints:** Prevent duplicate entities with UUID constraints
2. **Validation:** Validate data before database writes
3. **Rollback Strategy:** Implement transaction rollback on errors
